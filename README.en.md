## ✨ Key Features

- 💧 **Liquid Glass UI**: Translucent frosted glass background with liquid caustic light gradients.
- 🟩 **Dynamic 3x3 Status Bar Icon**: Status bar icon renders your real recent 9 days of GitHub contribution levels live.
- 🌱 **Dynamic Streak Badge Engine**: Emojis evolve based on streak progress (`0d 🌱` ➡️ `1-6d 🌿` ➡️ `7-29d 🔥` ➡️ `30-99d 🚀` ➡️ `100d+ 👑`).
- 🗓️ **Timeframe Range Selector**: Switch instantly between `1M`, `3M`, `6M`, and `1Y` view periods.
- 🌐 **Multi-Language Support**: Fully localized in English, Korean, Japanese, and Chinese.

```bash
brew tap mrKangHo/tap
```

```bash
brew tap mrKangHo/Grassie https://github.com/mrKangHo/Grassie
```
